# deploy/legacy-v1/ — quarantined v1 deploy artifacts

⚠️ **These files deploy the DORMANT v1 backend** (`original.main:app` + Postgres + Redis) — **not** the live pilot. The live deploy is `render.yaml` at the repo root (`python run.py --demo` serving `original/api.py` + `demo/`); see `docs/ARCHITECTURE.md` for the live-vs-dormant map. `Dockerfile`, `docker-compose.yml`, `docker-compose.override.yml`, `docker-entrypoint.sh`, `start-prod.sh`, and `fly.toml` were moved here from the repo root on 2026-07-07 (audit finding B15) and are retained for reference during the ADR-006 Postgres convergence, after which they will be retargeted to the converged stack or deleted. Only `Dockerfile.demo` (the live pilot image) remains at the repo root. Relative paths inside these files have been updated for the new location — build/compose from the repo root, e.g. `docker compose -f deploy/legacy-v1/docker-compose.yml up`.
