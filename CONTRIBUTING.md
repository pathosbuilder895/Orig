# Contributing

## Review checklist

- **Any PR that adds a route or a page adds or extends one E2E spec.**
  Specs live in `demo/bluebook/e2e/`; see `docs/implementation/WS-9-e2e-release-hygiene.md`
  for the current coverage plan and conventions (`@smoke` / `@a11y` / `@regression` tags,
  fixtures in `demo/bluebook/e2e/fixtures/`).
