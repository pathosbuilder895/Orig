# Google Form — "Original alpha test: feedback" (send when a volunteer has shared their four papers; async, no single session)

Build exactly from `google_forms_spec.md` §2. Questions/problems: Andrew Clark, arclark555@gmail.com.

1. How easy was it to sign in with your link and set a password? (1 = very hard … 5 = very easy, required)
2. While you were uploading, did the page ever feel slow, freeze, or lose anything? (No / Once / Several times + "what happened?" short answer)
3. Were the steps clear? (1–5, required)
4. Did sharing your four papers work? (Yes, first time / After some trouble / No)
5. What device and browser did you use? (Laptop–Chrome / Laptop–Safari / Laptop–Firefox / Laptop–Edge / Tablet / Phone / Other)
6. What was the most confusing or frustrating moment? (paragraph)
7. Anything you'd change before this is used with a real class? (paragraph, optional)
8. Anything about providing your past papers (including, if it applied, splitting one long paper) that was unclear or uncomfortable? (paragraph, optional)
(Before 2026-11 this form asked which AI tool wrote the volunteer's question 2 piece. Volunteers no longer make an AI piece, so that question is gone; `generator_tool` is the tool Andrew used for his imitation.)
