How the number is made

Each of the 97 measured habits is compared with the range this student shows across their teacher-approved samples. The deviation summarises how far the paper sits from those ranges, taken together: tanh(rms z / k).

The density matrix ρ = Σᵢ wᵢ |φᵢ⟩⟨φᵢ| summarises the same approved samples. It does not produce the deviation number. The fingerprint above is decorative, not drawn from ρ: it is the same print for every student.

With few approved samples the ranges are wide and uncertain, so an honest paper on a new topic can still drift. Read the habit-by-habit numbers before the overall reading.
